## Featured Projects

### Content-Based Music Recommendation System
A personalized music recommendation system that extracts audio features from the Spotify dataset, using vector similarity metrics to cluster tracks and generate playlists based on acoustic characteristics.

- **Tech:** Python, Clustering, Audio Feature Extraction, Spotify Dataset
- **Repository:** [View Repository](https://github.com/HansRic-5/content-based-music-recommender.git)

### Credit Risk Prediction with Streamlit & AWS SageMaker
Developed an end-to-end customer credit risk prediction system using Random Forest and XGBoost to handle imbalanced financial data. Built as an OOP modular architecture tracked with MLflow, deployed via AWS SageMaker with a Streamlit dashboard for real-time inference.

- **Tech:** Python, Scikit-learn, XGBoost, MLflow, Streamlit, AWS SageMaker
- **Repository:** [View Repository](https://github.com/HansRic-5/Credit-Risk-Prediction-Streamlit-and-AWS-Cloud-Model-Deployment-.git)

### Conditional GAN Image Generation
A Deep Convolutional GAN built with PyTorch to synthesize realistic aerial imagery, using TTUR, Label Smoothing, and Noise Injection to stabilize training and improve FID score from 343.99 to 198.10.

- **Tech:** Python, PyTorch, DCGAN, Computer Vision
- **Repository:** [View Repository](https://github.com/HansRic-5/conditional-gan-image-generation.git)
